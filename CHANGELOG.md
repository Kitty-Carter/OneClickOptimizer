# Changelog

## 0.1.0-alpha.1 — development preview
- Import the existing Positron optimizer and independent BAT launchers.
- Add module catalog, manifest, unified menu, Windows CI and isolated integration fixture.
- Add explicit backup-root override for tests and custom storage.
- Refuse automatic default-profile selection if a named profile flag is detected; prefer explicit running user-data path to portable guess.
- Recovery remains documented manual rollback. No automatic performance claim or second application module.
- Add bilingual branding, beginner Release ZIPs, SHA-256 checksums, standalone confirmation, and CI-gated preview publication.

## Clash Verge Rev module preview — batch 2

- Batch 1: guarded extension staging, exact original backup, config presets, catalog integration; no automatic live activation.
- Batch 2: optional read-only Windows monitor (per-adapter counters, CPU/RAM and Mihomo process resources), rate calculation tests and preset behavior tests. No native client fork, stable release or automatic monitoring installation.
