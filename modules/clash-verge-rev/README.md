# Clash Verge Rev 一键优化工具 · 1.2 稳定性候选版

## 普通用户使用
完整解压 Release ZIP，双击 Start.bat。无需 Rust、Python、Node.js 或 Git；Windows x64、PowerShell 5.1、已安装的 Clash Verge Rev、系统 curl.exe。不要在压缩包内部直接运行。启动时核对包内 SHA-256，文件损坏则停止（不是数字签名；二进制未签名）。

| 菜单 | 操作 |
|---|---|
| 1 | 只检查现有全局扩展，不修改 |
| 2 / Optimize.bat | 一键优化：默认扩展使用完整预设；自定义扩展自动降级为仅补缺失项，确认后写入 |
| 3 / Restore.bat | 列出本目录绑定的恢复记录，输入完整备份目录恢复 |
| 4 / 9 | 按需节点检测 / 全量筛选及候选生成 |
| 5 / 6 / 7 | 当前路径诊断 / 显式确认的 IPPure 单次检查 / 只读本地状态 |
| 8 | 仅补自定义 YAML 安全白名单缺失项 |
| V / R | 检查生成配置的19项完整预设目标 / 查看恢复记录 |
| A / P | 重新指定客户端及数据目录 / 手动指定代理端口 |
| 0 | 退出 |

自动定位通过运行进程、注册表、快捷方式、常用目录、有界磁盘搜索（非全盘穷举）；任意深层路径可手动指定。显式无效路径不会改选其他安装。真实数据目录独立定位；多个候选需选择。混合端口由 Rust YAML 解析，无法确认不默认猜测。只支持已验证的 2.5.10 / bundled Mihomo 1.19.33 自动写入；其他版本检查/诊断不等于支持修改。

## 配置优化与保护
完整预设源自 Merge v2.2、Script v2.3：TCP 并发、缓存与选项持久化、面向中国大陆网络的 Fake-IP/ARC/DoH DNS、规则精确去重、AI 固定出口及健康检查。请了解 DNS 预设适用性后确认；bootstrap UDP、provider 节点及未覆盖域名有边界，不是系统 kill switch，也不证明 DNS 无泄漏。自定义 YAML 只补 tcp-concurrent、profile.store-selected、profile.store-fake-ip；保留显式值（包括 false）、未知字段和 Script.js 原始字节；YAML 注释和格式可能改变。不改变原订阅、认证、TUN、MTU、系统代理、客户端二进制或防火墙。

正常退出 Clash 后再写；不强制终止软件。优化前私有 ACL 备份、当前目录身份摘要、原/新文件 SHA-256、事务状态落盘；每个文件原子替换、最终回读。跨进程互斥限当前 Windows 登录会话。异常退出留下可恢复记录：重新运行先拒绝未恢复事务；用 R 查找对应记录、3 恢复。不同目标目录、损坏备份、后续用户修改均拒绝。旧 1.1 备份没有身份摘要，请保留原版工具按原指引恢复，不能直接混用。恢复也需要退出 Clash；只恢复两个扩展，并非全应用恢复。完成写入的退出码 2 表示待手动激活（亦用于部分支持），不是自动成功。0 为所请求检查/自检或无修改通过，1 为失败/取消。启动 Clash，订阅页重新激活订阅；用 V 检查生成配置，再用 5 检查当前网络路径。V 的19项只检查生成文件，不能证明实际数据包、认证登录或实际选中节点；自定义配置不同于完整预设时部分项不同属正常。无缺失项不重复写入。

## 节点检测（Rust）
菜单4每批最多6个；ALL最多120个，2次 HTTPS 204，深测另含1 MiB 下载和 ChatGPT HTTP。菜单9 AUTO 最多120个合格内联 AnyTLS、VLESS、Hysteria2，3个隔离工作进程并行初筛，每个3次204，成功者按中位总耗时选前6再做3次204和2次1 MiB下载（响应体上限约36 MiB，不含握手及协议开销）。不删节点、不修改认证、不切换正式路径。候选仅为有限样本，不代表长期吞吐或可信身份；HTTP 200 不等同于认证使用。原 TUN 仍可能影响测试底层路径。不支持 provider-only/链式等节点。临时配置私有 ACL，Job 对象控制隔离内核；正常结束清理。突然终止可能留下 LocalAppData/OCO-Quality-* 私有目录，请确认无检测进程后自行清理。菜单6单次 IPPure 请求会向第三方暴露访问出口 IP，需确认；不批量请求。

策略组写入不在日常菜单中：过期、订阅更新和当前选择联动尚未获得正式网络验收。仍保留源码 CLI 的实验性 -PolicyFrom/-PolicyParent/-AllowExperimentalPolicy 供研究，普通用户不要使用；候选 YAML 不是可直接覆盖的 Merge.yaml。以手动选择原节点为稳定路径。没有实时网络/硬件监视或驻留服务。

## 验证边界
本机真实生成配置19/19；五份真实订阅模拟合并后由本机 Mihomo -t 验证；独立子进程首次文件替换后退出、残留事务检测和按原字节恢复、跨进程锁、包损坏/路径穿越测试。原始正式配置保持不变。真正的新电脑完整应用/激活/断网恢复和 TUN/MTU/UDP/DNS 上游测试仍未通过完整验收，因此为 release candidate，不保证通用稳定或提速。源码构建使用锁定 Rust 依赖，最终 ZIP 自带 EXE 与许可证。
