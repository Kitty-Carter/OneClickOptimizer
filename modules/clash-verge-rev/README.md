# Clash Verge Rev 一键优化工具 · 1.3.1 精简候选版

本版冻结功能扩张，默认只补充全局 Merge 中缺失的三个字段：tcp-concurrent、profile.store-selected、profile.store-fake-ip。不会自动写入整套 DNS、AI 分流、下载策略组或 Script.js；不主动迁移旧版自定义增强。保留原生订阅设计和现有显式值。全局补充可能仍影响订阅级同名值，请先检查实际需要；已有正常运行的配置无需重复优化。

## 使用
完整解压 Windows x64 ZIP，双击 Start.bat。无需开发环境；支持范围仍为 Clash Verge Rev 2.5.10 / bundled Mihomo 1.19.33 和官方 APPDATA 目录，非默认安装路径可发现，未知版本/数据目录只读。

| 菜单 | 功能 |
|---|---|
| 1 | 检查缺失字段计划，不写正式配置 |
| 2 / Optimize.bat | 仅补缺失三字段；正常退出 Clash 后确认 |
| 3 / Restore.bat | 恢复与目标绑定的原始扩展 |
| 4 | 按需节点检测，不改变选择 |
| 5 / 6 / 7 | 当前路径诊断 / 明确确认的单次 IPPure / 本地状态 |
| V / G / R | 结构审计 / 结构审计 / 恢复记录 |
| A / P / 0 | 手动路径 / 端口 / 退出 |

原生轻量模式、日志等级、AI 选择、DNS、TUN、MTU 均由用户在 Clash 中管理。旧版全量预设与实验模板仅保留为历史回归夹具，不再通过应用入口写入。不删除已有组，不自动切换节点。无实时监视或驻留程序。

写入前备份、目标绑定、哈希校验、文件级原子替换及可恢复事务保持原样。退出码2表示部分完成或待激活；正常启动后需重新激活订阅、检查实际配置及网络。结构检查不是 DNS 无泄漏、登录或提速证明。禁止将原始私有订阅、认证或节点候选打进公共包。

现有 v1.3.0-rc.1 历史包不变；本版仅减少默认干预。正式断网恢复及第二独立 Windows 仍未验证，故仅为候选版，不声称通用稳定或日常提速。
