Native-Monitor.bat: x64 Rust basic monitoring; close window to stop. Monitor.bat: richer C# hardware window. Restore.bat: guarded two-file OCO backup restore; close Clash first. Read README.md for limits.

Native-Monitor-Lite.bat: Rust monitoring without disk counters. Native-Monitor.bat also shows disk and Mihomo process counters when readable; use Monitor.bat for GPU. See latest section in README.md.

Diagnose.bat: current routed network health, sends six HTTPS requests. Inspect-Exit.bat: optional one-time IPPure query, confirm before sending; no raw IP saved. Default 7897; custom port via Diagnose-Clash.ps1 -Port PORT.
